        Cloud
        
      
        Speichere deine Server-Einstellungen in der Cloud, damit du sie auf jedem PC wiederfindest. Das Dashboard nutzt dafür einen Ordner, den deine Cloud-Software synchronisiert (OneDrive, Google Drive, Dropbox …). Es meldet sich bei keinem Cloud-Dienst selbst an.
        
      
        
        
        Cloud-Ordner
        
        
        
        
        
          
          
          
        
        
        
        
      
        
      
        
        
        Sichern
        
        
        Gesichert werden pro Server: Einstellungen, server.properties, Whitelist, OPs, Bans, Konfigurationsdateien (config, kubejs, Plugin-Einstellungen) und bei Modpacks die Modpack-Daten. Mods selbst und die Webhook-Adresse bleiben draußen.
        
        
        
        
          
          
        
        
        
        
          
          
        
        
      
        
      
        
        
        Server in der Cloud
        
        
        Alle Server, die in deinem Cloud-Ordner liegen, auch von anderen PCs. „Auf diesen PC holen“ legt einen neuen Server mit den gesicherten Einstellungen an. Mods oder Server-Datei lädt die Einrichtung danach frisch herunter.
        
        
          
      
          
    
          

    

    
          
      
          Meine Server
          
      
          Jeder Server hat eigene Welt, Einstellungen und Mods oder Plugins. Es läuft immer ein Server gleichzeitig. Zum Wechseln den laufenden Server erst stoppen.

Name, RAM und EULA nimmst du aus dem Formular darunter.

                              Im selben WLAN / Heimnetz
                              
        
                              Freunde im selben Netzwerk verbinden sich in Minecraft über Multiplayer → Server hinzufügen mit dieser Adresse:
                              
        
                              
        
                              Du selbst kannst dich auf diesem PC einfach mit localhost verbinden.
                              
      
                              
      
                              
        
                              Über das Internet (Portfreigabe)
                              
        
                                
          
                              1. Öffne die Oberfläche deines Routers im Browser (oft http://192.168.178.1 bei der FRITZ!Box oder http://192.168.0.1).
                                2. 
          
                              2. Suche nach Portfreigabe bzw. Port-Weiterleitung (FRITZ!Box: Internet → Freigaben → Portfreigaben).
                                3. 
          
                              3. Lege eine Freigabe an: Protokoll TCP, Port 25565, Ziel ist dieser PC (deine lokale IP).
                                4. 
          
                              4. Wenn Windows beim ersten Serverstart fragt, ob Java ins Netzwerk darf: Zulassen klicken.
                                5. 
          
                              5. Deine Freunde verbinden sich mit deiner öffentlichen IP:
            -
            
          
                                6. 
        
                              
        
                              Die öffentliche IP ändert sich bei vielen Anschlüssen regelmäßig. Gib die Adresse nur Leuten, denen du vertraust, und nutze am besten die Whitelist.
                              
      
                              
      
                              
        
                              Portfreigabe klappt nicht?
                              
        
                              Manche Anschlüsse (z. B. mit DS-Lite, Glasfaser oder Mobilfunk) erlauben keine Portfreigabe. Dann helfen diese kostenlosen Dienste:
                              
        
                                
          
                              • playit.gg: Kleines Programm starten, und deine Freunde bekommen eine feste Adresse. Sie müssen nichts installieren.
                                • 
          
                              • Tailscale: Ein privates Netz für dich und deine Freunde. Alle installieren Tailscale und verbinden sich dann mit deiner Tailscale-IP (100.x.x.x).

                              Bedrock-Support (Geyser)
                              
      
                              Damit können auch Spieler mit Minecraft Bedrock (Handy, Konsole, Windows-App) auf deinen Java-Server.
                              
      
                              
        
                              
        
                              Java und Bedrock, gemeinsamGeyser verbindet beide Editionen auf deinem Server.
                              
        
      
                              
      
                              
        
                               Installation
                              
        
                                
        
                                Geyser übersetzt zwischen Bedrock und Java. Floodgate erlaubt Bedrock-Spielern den Beitritt ohne Java-Account. Beide kommen von Modrinth und passen zu deiner Minecraft-Version.
                                
        
                                
        
                                Hinweis: Die Mods von Geyser und Floodgate stehen standardmäßig auf der Ausschlussliste. Beim Installieren werden sie dort entfernt.
                                
      
                                
      
                                
        
                                 Anmeldung der Bedrock-Spieler
                                
        
                                
        
                                
          
          
        
                                
      
                                
      
                                
        
                                 Verbinden
                                
        
                                Bedrock-Spieler brauchen eine andere Adresse und einen anderen Port als Java-Spieler: UDP 19132.
                                
        
                                
        
                                Für Freunde über das Internet musst du im Router zusätzlich UDP 19132 freigeben (wie bei der Portfreigabe unter „Freunde einladen“, aber Protokoll UDP).
